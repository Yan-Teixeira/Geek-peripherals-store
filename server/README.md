# Backend

Área reservada à API a ser implementada pelo responsável pelo backend.

Stack obrigatória: Node.js, Express, MongoDB, Mongoose e bcrypt. Organização proposta: `src/models`, `src/controllers`, `src/routes`, `src/middlewares`, `src/config`.

Implementar CRUD completo para pelo menos duas entidades relacionadas, autenticação, autorização de administrador/usuário e validação de entrada. A proteção de rotas no React não substitui autorização na API.

Veja `../docs/contrato-api.md` antes de integrar com o frontend. Não há servidor executável nesta pasta ainda.
